# PWA Icon Placement Instructions

To customize your PWA icons for Android / iOS app installation:

1. **`icon-192x192.png`** (192 × 192 px)
   - Place file at: `frontend/public/icons/icon-192x192.png`
   - Used for Android home screen icons & splash screens.

2. **`icon-512x512.png`** (512 × 512 px)
   - Place file at: `frontend/public/icons/icon-512x512.png`
   - Used for high-res splash screens, app stores, and PWA installation prompts.

If no specific 192x192 or 512x512 PNG file is provided, browsers automatically fall back to using `/logo.png`.
